# 稳健ETF量化助手

基于 VeighNa（vnpy 4.4）`vnpy.alpha` 模块二次开发的**多资产ETF趋势配置**工具。
给不懂交易的人用：每周看一次建议，按清单在券商APP里下单即可。

---

## 一、它做什么

在6类很少同时下跌的资产之间自动分配资金，每周调整一次：

| 大类 | 可选ETF | 作用 |
|---|---|---|
| A股大盘 | 沪深300ETF、红利ETF、红利低波ETF | 中国大公司 |
| A股成长 | 中证500ETF、创业板ETF、中证1000ETF、科创50ETF | 中小盘/科技成长 |
| 美股 | 纳指ETF、标普500ETF | 分散国别风险 |
| 黄金 | 黄金ETF | 避险 |
| 债券 | 国债ETF、十年国债ETF | 稳定收益，股票下跌时往往上涨 |
| 商品 | 豆粕ETF | 与股票相关性低 |
| 现金管理 | 银华日利 | 暂时不用的钱 |

**规则**（每周最后一个交易日收盘后计算，下个交易日开盘执行）：

1. **顺势**：只买价格在200日均线之上、近期上涨的ETF；已持有的要跌破均线5%才卖出。
2. **择优**：每个大类只买最强的一只，新的必须比手上的强3%以上才换。
3. **控险**：波动大的少买，单只最多30%；组合波动超过10%时整体降仓。
4. **避险**：卖出股票后空出来的钱转入趋势向上的国债ETF，其余放货币基金。

全部都是A股账户就能买的场内ETF，**不用加杠杆、不做空、不碰期货**，最坏情况也不会亏光本金。

## 二、历史表现（2014-06 至 2026-09，按真实规则模拟）

回测用的是 vnpy.alpha 回测引擎：周五收盘出信号、下周一开盘价成交、100份整手、每笔扣万5的佣金加滑点、分红再投资（后复权价格）。

| | 本策略 | 沪深300一直持有 | 货币基金 |
|---|---|---|---|
| 年化收益 | **8.9%** | 7.5% | 2.0% |
| 最大回撤（从高点最多跌了多少） | **-11.1%** | -44.4% | -0.5% |
| 夏普比率（>1为优秀） | **1.09** | 0.27 | — |
| 赚钱的年份 | 13/13 | 7/13 | 13/13 |

**这个策略为什么可信（不是凑出来的参数）：**

- **样本外表现一致**：2014-2019 年化 8.6%，2020-2026 年化 9.2%，前后两段差别不大。
- **参数不敏感**：均线换成60/120/200日，动量周期、波动上限、调仓阈值换成别的合理数值，年化大多在 7%~11%，最大回撤在 9%~17%，说明结果不依赖某个"碰巧好"的参数。
- **不偷看未来**：程序只用计算当天及以前的数据，有自动化测试专门检查（`tests/test_etf_quant.py`）。
- **没选"回测最好看"的方案**：只买一只、每天追涨的"动量轮动"回测年化 24%，但近几年明显变差、回撤 30%、每天都要交易，所以没有采用。

**请理性看待：**

- 历史不等于未来。回测中每年都赚钱，但**未来某一年亏 5% 左右完全可能发生**。
- 在大牛市里它会**明显跑输股票**（比如 2014 年下半年沪深300涨了 64%，它只涨了 14%；2019 年沪深300涨 35%，它涨 13%），因为它一直分散持有债券和黄金。这是稳定的代价。
- 历史上最长 528 天没创新高。需要以"年"为单位耐心持有。
- 预期年化 6%~10%，**不要指望靠它暴富**；它的价值在于比存款和理财收益高，同时波动小到普通人拿得住。

## 三、安装（只需一次）

1. 安装 Python 3.10~3.13（<https://www.python.org/downloads/>），安装时勾选 **Add python.exe to PATH**。
2. 双击仓库根目录的 **`安装环境.bat`**，等待 3~5 分钟，看到"安装完成"即可。

## 四、每周怎么用（5分钟）

双击 **`启动量化助手.bat`**，出现菜单：

```
  1. 本周操作建议（买什么、买多少）
  2. 我已按建议下单 → 更新持仓记录
  3. 查看我的持仓和收益
  4. 历史回测报告（策略过去表现如何）
  ...
```

1. **第一次**：先选 `4` 看看回测报告；再选 `1`，按提示输入你准备投入的资金。
2. **每周五 15:30 收盘后（或周末）**：选 `1`，程序会自动下载最新行情，给出下单清单，并在浏览器中打开详细说明。
   - 显示"本周不需要任何操作"→ 什么都不用做（大约三分之二的周都是这样）。
   - 有下单清单 → 下周一 9:30 开盘后，在券商APP里**先卖后买**，按清单的数量下单。
3. **成交后**：选 `2`，程序自动更新持仓记录。实际成交价和参考价略有不同没关系；如果数量有出入，用 Excel 打开 `etf_quant/workspace/持仓.csv` 手动改一下。

> 周中运行也没问题：本周还没结束时，程序给出的是上周五的信号；已经按它调过仓就会显示"不需要操作"。

### 强烈建议：先模拟1~2个月

第一次使用时输入一个金额，但**不真的下单**，只在每次出建议后选 `2` 记账。跑一两个月熟悉流程、感受一下波动，再投入真钱。

### 下单须知

- ETF 在券商APP里和股票一样买卖，代码直接输入6位数字（如 510300）。
- 数量必须是 **100 份的整数倍**，清单里已经算好。
- 价格：卖出填"买一价"、买入填"卖一价"，基本能立刻成交。
- 佣金：开户时可以跟券商要"ETF 佣金万一、免五"，能省不少钱。
- **纳指ETF / 标普500ETF 有时会"溢价"**（场内价格高于实际价值）。买入前在APP里看一下"溢价率"，超过 3% 就本周先不买这一只，留作现金，下周再看。
- **资金建议 10 万元以上**：国债ETF一手约 1.4 万元，钱太少时买不了整手，效果会偏离回测（程序会提示）。

### 纪律

这套方法有效的前提是**严格执行**。不要因为某一周涨了就追加、跌了就停止，也不要自己改参数——每个参数都已经做过稳健性检验，单独调某个参数让历史收益更好看，基本只会导致"过拟合"。

## 五、文件说明

```
etf_quant/
├── config.py       资产池、策略参数、交易成本（一般不需要修改）
├── data.py         行情下载（腾讯为主、东方财富备用，国内网站自动绕过代理），存入 vnpy.alpha AlphaLab
├── allocator.py    核心：目标仓位计算（回测与实盘共用同一个函数）
├── rebalance.py    目标仓位 → 具体份额（整手、偏离阈值、现金缓冲）
├── strategy.py     vnpy.alpha AlphaStrategy 子类
├── backtest.py     调用 vnpy.alpha BacktestingEngine 回测并计算指标
├── advisor.py      实盘操作建议、按建议更新持仓
├── portfolio.py    持仓文件（持仓.csv）读写
├── report.py       HTML 报告
├── cli.py          命令行与中文菜单
└── workspace/      你的数据（行情、持仓、报告），不会上传到 git
    ├── 持仓.csv        我的持仓，可用 Excel 修改
    ├── 净值记录.csv    每次调仓后的总资产记录
    └── reports/        回测报告、每周操作建议
```

命令行用法（懂技术的话）：

```bash
.venv\Scripts\python.exe -m etf_quant update                 # 更新行情
.venv\Scripts\python.exe -m etf_quant advice                 # 本周建议
.venv\Scripts\python.exe -m etf_quant apply                  # 按建议更新持仓
.venv\Scripts\python.exe -m etf_quant status                 # 查看持仓
.venv\Scripts\python.exe -m etf_quant backtest --capital 100000 --start 2016-01-01
.venv\Scripts\python.exe -m pytest tests/test_etf_quant.py   # 运行测试
```

### 与 vnpy 框架的关系

- 行情存储：`vnpy.alpha.AlphaLab`（Parquet 日线 + 合约交易配置）
- 策略：`SteadyAllocationStrategy` 继承 `vnpy.alpha.AlphaStrategy`，通过 `get_signal()` 读取每周目标仓位，`set_target()` + `execute_trading()` 调仓
- 回测：`vnpy.alpha.BacktestingEngine`，逐日撮合（次日开盘价、涨跌停检查、手续费）
- 只用到 vnpy 的无界面部分，不需要安装 PySide6 等图形界面依赖

以后如果想接入券商接口自动下单，可以在此基础上接 vnpy 的交易网关（例如 vnpy_xt 对接迅投QMT），但**对新手不建议自动交易**，手动下单更安全、也更容易理解自己在做什么。

## 六、常见问题

**Q：下载行情失败？**
A：程序会自动在直连和系统代理之间切换重试，并在腾讯、东方财富两个数据源之间切换。仍然失败就过几分钟再试；失败时会继续使用本地已有数据。

**Q：我已经持有其中一些ETF？**
A：用 Excel 打开 `etf_quant/workspace/持仓.csv`，按格式填上代码和份额，保存后再生成建议。不在资产池里的股票/基金程序会忽略。

**Q：可以中途加钱或取钱吗？**
A：可以。在 `持仓.csv` 里修改"现金"那一行，下次生成建议时会自动按新的总资产重新分配。
